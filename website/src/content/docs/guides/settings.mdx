Open the settings with the gear button at the top right of the organizer. Changes are saved at once, on your computer.

## Default choices

| Setting                                  | Default        | What it changes                                                                  |
| ---------------------------------------- | -------------- | -------------------------------------------------------------------------------- |
| Organize into                            | Bookmarks bar  | Where the new top-level folders go. Adult content, unreachable sites and bookmarks to check always go to Other bookmarks. |
| Folder names                             | Emoji only     | Emoji only, Emoji + name or Name only. Subfolders keep their names.              |
| Quick access                             | 10             | How many icons of your most visited sites open the bookmarks bar: none, 5, 10 or 20. |
| Bookmarks bar as icons                   | On             | Shows the quick access bookmarks as icons only.                                  |
| Read sites when the title is not enough  | On             | Reads the page of the bookmarks the title does not explain.                      |
| Find sites that no longer answer         | On             | Checks every bookmark in the sort and sets dead links apart.                     |
| One copy of each page                    | On             | Recreates one copy of each page; the others stay in the backup.                  |
| Put the most visited sites first         | On             | Counts the visits of each site in your history, on this computer, for quick access and the order of the folders; reads the page titles your browser already stored for titles such as "Home". |

Reading sites and finding dead links need access to sites; putting the most visited sites first needs the history permission. Chrome asks for both in one prompt at the next analysis, or for the history when you turn it on here. See [Privacy and permissions](/reference/privacy/).

## Backups

Lists the backup folders Nidomark made, each holding a previous tree, with the number of bookmarks inside. **Delete** removes one after a confirmation: your new tree does not move, but the sort that made it can no longer be undone.

## Data

- **Icon-only bookmarks**: the number of bookmarks shown as icons only, and **Show all names again**.
- **Analysis cache**: what the model computed for each bookmark, kept to speed up the next analyses. **Clear** deletes it.
